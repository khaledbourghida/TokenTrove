Common Errors & Solutions

Find quick solutions to the most common issues with our Free Fire diamonds app.

Download Issues

App won't download or install
1. Enable "Install from unknown sources" in Android Settings > Security
2. Clear browser cache and try downloading again
3. Make sure you have enough storage space (at least 100MB)
4. Try downloading using a different browser
"App not installed" error message
1. Uninstall any previous version of the app
2. Restart your device
3. Download the latest APK file
4. Install with "Install from unknown sources" enabled

Token & Ads Issues

Ads not loading or showing
1. Check your internet connection
2. Close and reopen the app
3. Wait for the 60-second cooldown to finish
4. Try switching between WiFi and mobile data
5. Restart your device if problem persists
Tokens not being added after watching ads
1. Make sure you watch the complete ad (don't skip)
2. Wait a few seconds after the ad finishes
3. Check your internet connection
4. Force close and reopen the app
5. Contact support if tokens still missing after 5 minutes
"No ads available" message
1. This is normal - ads refresh every few hours
2. Try again in 30-60 minutes
3. Make sure your device date/time is correct
4. Clear app cache in Android Settings > Apps > FF Diamonds > Storage

Diamond Exchange Issues

Diamond request not processed
1. Diamond requests are processed within 24 hours
2. Make sure you provided correct Free Fire ID
3. Check if you have enough tokens for the exchange
4. Contact support with your request ID if delayed beyond 24 hours
Wrong Free Fire ID entered
1. Contact support immediately with correct ID
2. Provide your request ID and correct Free Fire ID
3. We can update the ID before processing
4. Double-check your ID before submitting future requests

Account Issues

Can't login or register
1. Check your internet connection
2. Make sure you're using a valid email address
3. Try using a different email provider
4. Clear app data and try registering again
5. Contact support if problem continues
Lost tokens or progress
1. Make sure you're logged into the same account
2. Check your internet connection
3. Force close and reopen the app
4. Wait a few minutes for data to sync
5. Contact support with your account email if data doesn't restore

Competition & League Issues

Not showing on leaderboard
1. Leaderboard updates every hour
2. Make sure you've watched at least 5 ads
3. Check if competition is currently active
4. Refresh the leaderboard by pulling down
5. Contact support if still not showing after 2 hours
Didn't receive competition prize
1. Prizes are distributed within 48 hours after competition ends
2. Check your account balance for added diamonds
3. Make sure you finished in top 3 positions
4. Contact support with screenshot of your final position
